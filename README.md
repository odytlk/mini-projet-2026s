# Gestion d'une cafétéria universitaire

Projet Python en console (sujet 1 du devoir).

## Participants
- Blaise Christopher Alexandre
- Arcelin Yves Odelin

## Description
Application pour gérer les ingrédients, les produits, les clients et les commandes d'une cafétéria. Les données sont sauvegardées dans `donnees.json`.

## Lancement
1. Placer `donnees.json` dans le même dossier que le programme.
2. Lancer le programme : `devoir3.py`
3. Menu : 1 = étudiant, 2 = professeur, 3 = admin.
